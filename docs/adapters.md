# Droid and Oh my Pi adapters

## Register an identity and canonical scope

Run `examples/connect.py` with your private owner credential file to register an agent and
a canonical work scope. It prints IDs, not credentials. Give the scope explicit
workspace-relative `allowed_paths`, such as `src/header`.

Issue a separate credential with the local administration CLI:

```powershell
.\.venv\Scripts\hivemind.exe issue-token --role agent `
  --project PROJECT_ID --agent AGENT_ID --capture-authority `
  --out ABSOLUTE_PRIVATE_AGENT_CREDENTIAL_PATH
```

The credential's project/agent binding governs access. `--capture-authority` is an explicit
local trust grant to the runtime instrumentation. Only add `--coordinator` for a deliberately
authorized Nexus candidate. An agent cannot add that grant through its manifest or API.

Extend the private credential JSON, outside source control:

```json
{
  "base_url": "http://127.0.0.1:8765",
  "token": "<credential generated by the CLI, never commit>",
  "project_id": "<project ID>",
  "agent_id": "<agent ID>",
  "runtime": "droid",
  "workspace_root": "<absolute dedicated worktree root>",
  "state_dir": "<absolute private adapter state directory>",
  "scope_ids": ["<canonical scope ID>"],
  "intent": "Implement the website header",
  "flush_interval_seconds": 5
}
```

Use `"runtime": "oh-my-pi"` for Oh my Pi. Each runtime/session gets an independent run.
Changing an already-created session's initial scope requires a new claim or a steering control.

## Five-second publishing process

Short-lived hooks spool ordinary events rather than spawning a new daemon for every tool.
Run this explicit, long-lived local process alongside each configured runtime:

```powershell
.\.venv\Scripts\python.exe -m hivemind.capture_daemon --config ABSOLUTE_PRIVATE_CONFIG
```

It drains durable, redacted SQLite spools every five seconds, publishes capture health,
heartbeats registered runs, and renews valid active claims. Stop it when those sessions
finish; presence goes stale/offline without inventing a task failure.
Session startup reports immediately. Messages, board posts, claims, and controls use
direct API commands, not the observation buffer.

## Factory Droid

Review `adapters/droid/hooks.example.json`. Replace both absolute-path placeholders.
Merge the example into the intended project's `.factory/settings.json` through Droid's `/hooks`
manager. Do not overwrite existing hooks. Restart/reload the runtime as required by Droid.

Validated against the documented SessionStart/PreToolUse/PostToolUse JSON contract and
installed Droid `0.233.0`. The bridge exits `2` to deny an operation and never emits an
`allow` decision that bypasses the host's ordinary approval.

The adapter supports `Create`/`Edit` with a concrete `file_path`, and bounded `ApplyPatch`
envelopes supplied as raw text or a `patch`/`input` field. It checks every add/update/delete/move
path, including both sides of a move, before permitting the tool. Unknown patch directives
or input shapes fail closed. Shell `Execute`, delegated tools, and arbitrary MCP mutations
remain blocked because their file effects cannot be safely bounded.
Read/Glob/Grep/LS and documented fetch/search tools are read-only.

The opt-in [Factory integration harness](factory-integration.md) configures
`allowed_mcp_tools` with exact local Hivemind tool IDs discovered from the
Factory inventory. This is an administrator-controlled allowlist, not a wildcard
MCP bypass; the tools still use the agent-bound API credential. Do not list
arbitrary tools or tools capable of shell/filesystem execution. Optional
`restrict_reads_to_workspace` and `max_tool_calls` enforce the harness's read
boundary and per-session budget. Hooks can use `HIVEMIND_CONFIG` instead of
`--config`, keeping private config paths out of project hook settings.

## Oh my Pi

Validated against installed Oh my Pi `18.3.2` extension types:
`session_start`, blocking `tool_call`, and `tool_result`.

```powershell
$env:HIVEMIND_CONFIG="ABSOLUTE_PRIVATE_CONFIG"
$env:HIVEMIND_PYTHON="G:\Droid\Hivemind\.venv\Scripts\python.exe"
omp --extension G:\Droid\Hivemind\adapters\oh-my-pi\hivemind.ts
```

The extension supports `write`/`edit` with a concrete path and blocks uncontrolled shell,
Python, browser, notebook, and custom mutations. `/hivemind` shows the connection/project.
Host tool results supply `isError`; Droid results lacking a reliable success flag remain
`success: unknown` rather than asserting success.

## Checkpoints and limits

Controls are processed only at a safe boundary before a new tool, never by interrupting
an in-flight file write. A pending earlier controlled edit blocks another tool until its
completion is observed. The adapter persists applied control IDs and pending results,
reconciles after a crash, switches local assignment/scope state, and reports a checkpoint.

A steering transition rejects a mutation already planned for the old assignment and remains
`applying` after its checkpoint. Read-only discovery can consume that checkpoint safely
and receive the pending assignment without inventing work completion. Subsequent calls
receive the new task's context and obtain
a transition permit only for the reserved replacement scope. The control becomes `applied`
only after a scoped replacement operation is observed, not merely when an assignment is queued.
Pause/cancel stop subsequent mutations; neither rolls back completed writes.
An agent must actually attempt another tool for these hook-based controls to be applied.
Acknowledgment alone does not mark a control applied.

This is a cooperative tool-boundary guard, not an OS sandbox. Use separate worktrees.
Malicious code or tools outside these hooks are not constrained. Symlink real-path containment
is checked before/after file observations, but an adversarial symlink race requires OS-level
sandboxing beyond this milestone.

Existing global runtime settings and pre-existing user sessions were not modified.
The opt-in Factory integration scenarios create and resume their own real model-driven
sessions in isolated generated projects. Live Oh my Pi sessions have not been launched.
